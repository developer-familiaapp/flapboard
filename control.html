Connect your board

The phone and the TV talk through a free Firebase database in your Google account. This takes about five minutes, once.

  1. Open console.firebase.google.com and sign in with your Google account. Click Create a project, name it flapboard, turn off Google Analytics, and create it.
  2. In the left menu open Build → Realtime Database and click Create Database. Pick a location, choose Start in locked mode, then Enable.
  3. Open the Rules tab, replace everything with the rules below, and click Publish.
  4. Back on the Data tab, copy the address at the top (it ends in firebaseio.com or firebasedatabase.app) and paste it here.
Database rules 
{
  "rules": {
    "boards": {
      "$board": {
        ".read": "$board.length >= 24",
        ".write": "$board.length >= 24"
      }
    }
  }
}
